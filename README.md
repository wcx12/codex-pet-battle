# Codex Pet Battle

Codex Pet Battle is an experimental companion project for Codex Pets.

The long-term idea is to turn Codex usage into a small RPG loop:

- pets gain experience from Codex activity and token usage
- leveling unlocks forms, traits, and skills
- local pets can sync to an account later
- two users can eventually battle their Codex pets

This repository starts as a public planning and implementation space. The first milestone is a local MVP that reads Codex session usage, computes pet experience, and stores a simple pet state.
